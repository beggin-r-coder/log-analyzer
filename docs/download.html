Which one should I pick?

  • Just want to use it: LogAnalyzer.exe.
  • Want it in the Start menu: the installer.
  • Want to run or change the code in Eclipse on a work laptop: the offline Eclipse project. In Eclipse use File → Import → General → Existing Projects into Workspace, then run Log Analyzer - desktop app from the Run menu.
  • Developer with Maven access: the source code.

First start

  1. Windows SmartScreen may say the app is from an unknown publisher, because it is not code-signed. Click More info → Run anyway.
  2. Log Analyzer opens in its own window and asks where your logs are: a Siebel log folder, a database (Oracle, SQL Server, PostgreSQL, MySQL), or an Excel / CSV file. Or try it with sample Siebel logs.
  3. It keeps running in the system tray. Use Quit in the app or the tray menu to stop it.
